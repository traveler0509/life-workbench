# 生活工作台 · Life Bench

一个**单文件、零依赖、纯本地**的个人生活管理工作台。双击 HTML 就能用，不需要装环境、不需要联网、不需要注册。

> 把「系统记不了的」记下来，剩下的交给手机自带功能。

---

## 为什么做这个

手机系统（以小米澎湃OS 4 为例）已经覆盖了不少能力：

- 小米钱包的 **AI 自动记账**会自动抓微信/支付宝流水并分类出报表
- 系统**日历 + 超级小爱灵感球**能指着海报一句话加日程，还带推送提醒

这些用系统就够了，重复造一遍没有意义。所以这个工作台**主动砍掉了记账和日程**，只保留系统做不到的部分：

| 系统做不到的 | 工作台怎么做 |
|---|---|
| 自定义打卡（勾选 / 计数 / 数值） | 三种打卡方式 + 30 天热力图 |
| 习惯的「坚持质量」评估 | 加权近因的习惯评分 |
| 预算管控与超支预警 | — |
| 待买清单的优先级与金额合计 | 按优先级分组 + 合计 |
| 书影音的状态、星级、短评 | 封面墙 / 列表 + 年度统计 |
| 跨模块汇总视图 | 今日生活指数 |

---

## 功能

**今日概览** — 生活指数（4 维加权）、时间进度、今天要处理、今日习惯快捷打卡、近 30 天节奏（综合热力图 + 体重趋势）、本周小结、最近动态、清单与收藏摘要。

**习惯健康** — 勾选 / 计数 / 数值三种打卡方式；30 天热力图；习惯评分（加权近因）；当前连续、历史最长、全勤天数、等权完成度对照。

**减脂健身** — 体重与体脂记录；7 日均线折线图；BMI 自动分级；目标进度条；近 7 天 / 近 30 天变化；按当前速度外推的**预计达成日期**；**训练记录**（部位 / 动作 / 组数 × 次数 × 重量 / 时长 / 消耗，内置 9 个部位的动作库）；**训练容量趋势**（近 8 周吨位柱状图）；**动作进步**（最大重量与增幅，自动标记 PR）；部位分布；本周计划 vs 实际对照；热量缺口（含运动消耗与近 7 日累计、折算脂肪）；可逐格编辑的周训练计划。

**待买清单** — 优先级分组、预估金额合计、类别分布、勾选归档、已入手统计。

**书影音收藏** — 书 / 影 / 音，状态、五星评分、短评、封面墙 ⇄ 列表切换；年份切换的年度小结（新增、已完成、平均评分、短评比例、类型占比）。

**数据与设置** — 个人参数、模块状态、备份与恢复、危险操作。

## 快速开始

1. 下载 [`生活工作台.html`](./生活工作台.html)
2. 用浏览器打开

就这样。没有构建步骤，没有依赖安装。

> **手机上使用**：建议用浏览器打开后「添加到桌面」，之后固定从那个图标进入。直接在文件管理器里点开走的是 `file://` 协议，换一种打开方式可能导致数据不可见。

## 两个文件说明

| 文件 | 说明 |
|---|---|
| `生活工作台.html` | **精简版**，日常使用。6 个模块，界面为当前最新版本 |
| `生活工作台-完整版.html` | **功能备份版**，额外包含「记账理财」与「日程统筹」两个模块 |

两个文件**共用同一份本地数据**（localStorage 键 `lifebench.v1`）。精简版虽然不显示记账和日程，但保存时会把这些数据原样写回，不会丢。打开完整版即可查看与继续使用，可随时来回切换。

## 数据与隐私

- 所有数据只存在**你自己设备的浏览器**里，不上传任何服务器，代码里没有任何网络请求
- 存储键：`lifebench.v1`
- **JSON 导出 / 导入**：导入支持任意条数，可选「合并」或「覆盖」
- **新增满 20 条**会提醒你备份
- **存储失败**（无痕模式、空间已满）与**数据损坏**会分别给出明确提示，并提供恢复入口
- 首次打开会预置少量演示数据，可在「数据与设置」里一键清空，**不会影响你自己添加的记录**

> ⚠️ 清理浏览器数据、切换浏览器或更换设备都会导致数据不可见，请定期导出备份。

## 技术要点

单文件 HTML，CSS / JavaScript / 图标 / 图表全部内联，**零外部依赖**。

- **图表全部手绘 SVG**：环形进度（`stroke-dasharray`）、甜甜圈、折线（含面积填充与均线）、迷你趋势图、GitHub 式热力图
- **存储容错**：`normalize()` 对全部字段做类型清洗与兜底，写入用 `try/catch` 区分「存储失败」与「数据损坏」
- **声明式表单构建器**：`openForm({fields})` 支持 text / number / select / textarea / 星级 / 取色器，大幅压缩弹层代码
- **事件委托**：统一在 `document` 上监听 `data-act` 属性，避免重复绑定
- **字号层级**：全站最小字号 12.5px，关键信息（日期等）提到独立层级，移动端整体再上移一档

### 习惯评分算法

参照 [Loop Habit Tracker](https://github.com/iSoron/uhabits) 的加权近因思路：

```
score = Σ w(i)·v(i) / Σ w(i)      w(i) = e^(−0.1·i)
```

- 30 天窗口，λ = 0.1，半衰期 ≈ 6.93 天（一周前权重只剩一半）
- `v(i)` 为单日完成度：勾选类 0/1，**计数与数值类取 min(值/目标, 1) 给部分分**
- 新习惯按实际存在天数收窄窗口（最少 7 天），避免刚创建就被压低
- 效果：同样完成 10 天，集中在最近 10 天与集中在 20–30 天前，**评分差 20 分以上**，而等权完成度完全相同
